# Hunt: Showdown 1896 — Loadout Roulette

A single-page web app that generates semi-random, valid Hunt: Showdown 1896 loadouts based on your preferences.

- No build step required.
- Open `index.html` in any browser.

Features:
- Loadout Styles: Balanced, Aggressive Rush, Sniper, Stealth, Weird & Fun
- Synergy Mode: coherent primary/secondary pairings and style-matched equipment
- Meta-informed weighting (healing, explosives, range coverage)
- Per-roll flavor note explaining why the loadout is good

Usage:
- Open index.html in your browser.
- Adjust preferences on the left, then hit ROLL.
